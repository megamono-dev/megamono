# Trigger fixtures

## Positive prompts

- Review whether we can align React across all applications.
- Check this new dependency against every project constraint.
- Does adding this package violate our dependency direction?
- Review the Expo, npm, and Cargo compatibility impact of this upgrade.
- Find every consumer before we change this shared dependency.

## Negative prompts

- Install the exact dependency version I specified.
- Explain what semantic versioning means.
- Fix an import path without changing dependencies.
- List the dependencies in this one package.json.
- Run npm install after the approved manifest change.
