# Trigger fixtures

## Positive prompts

- Review which active plans are ready to archive.
- Find stale repository documents that need lifecycle attention.
- Check whether merged branches left plans in the hot corpus.
- Propose archive candidates without moving anything.
- Review expired reports and superseded research records.

## Negative prompts

- Archive this specific plan as completed.
- Delete these confirmed expired reports.
- Generate a new research record.
- Show every file under docs.
- Update the status of this decision.
