# Archive Review

Use this skill when a maintainer asks which documents are stale or ready to leave the hot corpus.

Inspect repository health, plan branches and last changes, project existence, superseding decisions, and report retention metadata. Separate strong terminal candidates from items needing human judgement, and cite stable document IDs.

This skill proposes only. Do not move documents, change terminal status, delete reports, or rewrite references. After explicit approval, use `megamono-docs:archive` or `megamono-docs:prune-reports` so lifecycle changes remain deterministic and validated.

For routing examples, read [references/triggers.md](references/triggers.md).
