# Documentation Placement

Use this skill when the destination or document type is unclear.

Classify the artifact by purpose and lifecycle: durable intent belongs in specs, active execution in plans, durable choices in decisions, evaluation against a standard in audits, exploration in research, and observations in reports. Keep publishable content in its content-level collection rather than the repository corpus.

Recommend the canonical generator and required metadata. Preserve the direction rule: repository docs may reference public content, while published content must not depend on internal repository documents. Do not create a new taxonomy bucket without an accepted contract.
