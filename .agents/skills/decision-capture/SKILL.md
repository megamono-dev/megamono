# Decision Capture

Use this skill when a choice will constrain future work and the user wants it recorded.

Search `docs/INDEX.md` and relevant specs for an existing decision. If the choice is genuinely durable, use the repository decision generator, record the selected option and consequences, and reference the evidence that shaped it. Supersede rather than rewrite an accepted decision.

Do not create decision records for routine implementation details, reversible local choices, or unresolved research. Never infer acceptance from discussion alone; leave the record proposed unless the user explicitly confirms the decision.

For routing examples, read [references/triggers.md](references/triggers.md).
